## 📝 Catatan Penting

1. **Pastikan nama file sesuai persis** dengan yang tercantum di atas (case-sensitive)
2. **Aspect ratio harus sesuai** untuk hasil terbaik:
   - About Us: **4:3**
   - Vision, Mission, Core Values: **4:5**
3. **Ukuran file**: Disarankan maksimal 500KB per image (optimalkan dengan kompresi)
4. **Format**: JPG untuk foto, PNG untuk gambar dengan transparansi, WebP untuk performa terbaik
5. **Setelah upload**, image akan otomatis digunakan di halaman Company Profile
